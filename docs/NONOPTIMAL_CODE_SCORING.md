# 非最优码的整段单字奖励（2026-10-09）

生产默认取消单字主码的 `2 × 码长` 奖励，不再沿句内主码片段累计此加分。

整个原始输入由单一码表边消费、没有显式选重符号、输出恰好一个汉字时，奖励仍为 `+5`。
如果该字位于用户设置的字频前 N 名且不在白名单，额外要求匹配最优码（码表中的最短编码，同长按源顺序）。
其它字使用任意码表已有的合法完整匹配编码都满足此奖励条件。

`high_freq_limit` 和白名单继续使用用户当前值；默认 N=1500，N=0 时这一奖励不再要求最优码。
词库原有主码过滤保持不变。主码与最优码并不等价：主码优先合法组句、同码首选及短码，最优码可为一码。
本次不新增编码，不放宽显式选重、单字重码组句或一句内一码片段的语法限制。

句内单字片段、多字词和显式选重不领取整段单字奖励。
整段 `+5` 始终从 confidence mass 中扣除；主码完整四码的孤立生僻字保护、词先验、个人学习及纠错8/6/4保持原规则。
测试参数接口可恢复历史奖励用于消融与构造非首选学习场景，生产入口不调用该接口。

## 验证

`tools/test_whole_single_reward.lua` 通过真实码表和确定性模型检查 N=0/1500、阈值边界、白名单、最优/非最优、显式选重、整句与置信度隔离。
`tools/run_regressions.py` 仍覆盖增量/全量一致性、高频过滤、提前上屏、锁定回放、纠错与可读自学习。

跨后端完整离线准确率报告位于 2026-10-08 的虎娘实验目录；它不等于所有 Rime 前端的实机准确率或时延测量。
